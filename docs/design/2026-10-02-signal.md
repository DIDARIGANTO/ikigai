# Ikigai — дизайн v4 «Сигнал»

Статус: запрошено владельцем 02.10.2026 — «все нравится, цвет хочется сделать брутальнее, как на S.A.T» (https://sat-official.vercel.app/ru).
Это **перекраска и смена характера поверх v3 «Графит»**: структура экранов, компоненты и логика не менялись, токены сохранили имена.
Ориентир — сайт студии владельца S.A.T Group: чернильный фон, бумажный текст, один кислотный лайм, красные метки, острые углы, волосяные линии, капитель с трекингом.
Тёмная тема по умолчанию; светлая — «бумага и чернила».

> **Обновление 02.10.2026 (позже):** «Сигнал» стал одним из пяти выбираемых стилей — см. `docs/design/2026-10-02-styles.md`. Раздельного переключателя «тёмная/светлая» больше нет; светлый вариант из этого документа заменён отдельным образом «Светлый» (белая страница, мягкие углы). Значения «Сигнала» ниже действительны.

## 1. Что изменилось относительно «Графита»
| | v3 «Графит» | v4 «Сигнал» |
|---|---|---|
| Фон (тёмная) | графит `#0E0F11` | чернила `#080909` |
| Текст (тёмная) | `#ECEDEF` | бумага `#F1F0EA` |
| Акцент | индиго `#5B64E3` | сигнальный лайм `#D4FF3A` (текст на нём `#0B0D00`) |
| Красный | роза `#F0707F` | `#FF3D2E` — метки «важно», опасность |
| Линии | 8 % / 14 % | 12 % / 24 % (тёмная), 14 % / 28 % (светлая) |
| Радиусы | 12 / 8 / 6 | **4** карточка и лист, **2** поле, кнопка, чип, плитка |
| Подписи | 12 px, не заглавные | **капитель** 11 px, трекинг 0.14em, верхний регистр (`label-caps`) |
| Заголовки | 600, обычный регистр | 500, **верхний регистр** (`PageHeader`, приветствие) |
| Метки/точки/полосы | круглые | **квадратные** (как лаймовый квадрат после точки на S.A.T) |
| Выделение текста | полупрозрачный акцент | сплошной сигнальный блок: лайм с чернильным текстом |

Правило v3 «никаких заглавных с разрядкой в подписях» **отменено**: это фирменная черта S.A.T. Остальные пункты «теста щегла» действуют (градиенты, пилюли, эмодзи-плитки, конфетти, отскок — по-прежнему нельзя).

### Светлая — бумага и чернила
canvas `#F1F0EA` (paper), panel `#E9E8E1`, sunken `#E3E2DA`, surface `#F8F7F3`, raised/overlay `#FCFBF8`, text `#0B0D0A`, muted-strong `#3B3E3A`, muted `#5C605D`, control-border `#7A7E7A`,
border / border-strong — чернила 14 % / 28 %.
**Лайм на бумаге не читается**, поэтому пара переворачивается: accent = чернила `#0B0D0A` (hover `#2A2E2A`), on-accent = лайм `#D4FF3A` (отметка дня в календаре — чёрный квадрат с лаймовой цифрой), а лайм остаётся «маркером»: accent-soft = лайм 42 % на поверхности (подсветка выбранного).
Метки темнее, чтобы держать ≥ 3:1 к бумаге: indigo `#4A52E8`, mint `#0A9F78`, rose `#E02619`, amber `#C27C00`, lilac `#7B44E0`, sky `#0A8DB5`, lime `#6F8F00`, coral `#E0531F`, sun `#9A7D00`; danger `#D91F11`, danger-strong `#C41A0C`.

### Где живёт лайм (сигнал, а не заливка экрана)
Фокус-кольцо, выбранное, галочка и дорожка прогресса, линия и метка «сейчас», отметка сегодняшнего дня, точка-метка, иконка активного раздела, плавающая кнопка «+» на телефоне, выделение текста, ядро знака.
**Главная кнопка остаётся монохромной** (бумага на чернилах / чернила на бумаге), как на S.A.T: лаймовой заливки у больших кнопок нет.

## 3. Типографика
Geist (текст), Geist Mono (время, числа), **Noto Serif Display Italic** (`serif-accent`, вес 350) — только акцентное слово: имя в приветствии «ДОБРОЕ УТРО, *Дидар*». Не больше одного такого слова на экран.
- `label-caps`: 11/14, 500, трекинг 0.14em, верхний регистр — подписи полей (`LABEL`), группы меню, заголовки малых секций, дата над приветствием.
- Заголовок страницы: 24/30, 500, верхний регистр, −0.025em. Приветствие «Сегодня»: 28/34, 500, верхний регистр, −0.03em.
- Знак: «IKIGAI» 500 капителью, трекинг +0.08em.
- Заголовки карточек (h2/h3) остаются обычным регистром — капитель только для подписей и страниц.
- Кнопки и пункты меню — обычный регистр (в приложении их читают сотни раз в день; капитель там только мешает).

## 4. Формы
- Радиусы: токены `--radius-card/sheet` 4 px, `--radius-control/chip/tile` 2 px; шкала Tailwind (`rounded-sm … 3xl`) сжата до 2–4 px, так что любой `rounded-*` в коде остаётся острым.
- Точки-метки, полосы и дорожки прогресса — **квадратные** (`rounded-none`); круглым остаётся только радио (иначе его не отличить от чекбокса).
- Тумблер: прямоугольная дорожка 30×18, квадратный бегунок «вырезом» цвета холста (включён — цвет текста на акценте).
- Отметка сегодняшнего дня (месяц и неделя) — квадрат с острыми углами в сигнальном цвете.
