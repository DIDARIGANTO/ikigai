# Ikigai — дизайн v3 «Графит»

Статус: утверждено владельцем как направление 01.10.2026 (после отказа от «самурая», «шаблона Notion» и игрового «Горизонта»).
Ориентиры: **Linear, Raycast, Arc, Vercel/Geist, Notion Calendar, Superhuman**. Характер: *инструмент мастера* — спокойный, точный, плотный, дорогой на вид.
Тёмная тема по умолчанию; светлая проработана так же тщательно.

> **Обновление 02.10.2026:** палитра, радиусы и подписи заменены на v4 «Сигнал» — см. `docs/design/2026-10-02-signal.md` (чернила/бумага/лайм, углы 2–4 px, капитель в подписях). Структура экранов, компоненты и остальные правила «теста щегла» ниже действуют; значения цветов, радиусов и запрет на заглавные подписи — нет.

## 1. Принципы
1. **Сдержанность.** Интерфейс нейтральный. Цвет несёт смысл (выбор, прогресс, статус), а не украшение. Один акцент.
2. **Точность.** Сетка 4 px, линии в 1 px с малой непрозрачностью, одинаковые радиусы и высоты строк везде.
3. **Типографика делает работу.** Иерархия — вес и размер, а не цвет и плитки. Числа — табличные, время и таймеры — моноширинные.
4. **Плотность профессионального инструмента.** Строки 32–40 px, текст 14 px, аккуратные отступы; без «воздуха ради воздуха».
5. **Тихое движение.** 100–220 мс, `ease-out`, без пружин и отскоков, без конфетти. Движение подтверждает действие, а не развлекает.
6. **Содержимое важнее рамок.** Меньше коробок в коробках; списки и разделители вместо россыпи карточек.

## 2. «Тест щегла» — обязательная проверка каждого экрана
Экран **не принимается**, если на нём есть хотя бы одно из:
- градиенты, «небо», солнце/луна, иллюстрации, маскоты, декоративные блики;
- округлые или широкие display-шрифты (Unbounded и подобные), заголовки крупнее 28 px;
- пастельные цветные плитки/квадраты за иконками и эмодзи; разноцветные «конфетти»-палитры;
- кнопки-таблетки, радиусы карточек больше 14 px;
- отскок, покачивание иконок, конфетти, «салюты»;
- эмодзи как элемент интерфейса (эмодзи допустимы только как содержимое, выбранное человеком, и без цветной плитки);
- больше одного хроматического акцента в области экрана (не считая семантики: успех/предупреждение/ошибка);
- заглавные буквы с разрядкой в подписях, восклицательные знаки, «милые» тексты;
- теснота без выравнивания: любой элемент не на сетке 4 px.
Плюс «проверка дорогого»: не более 4 размеров шрифта на экране; один вес для подписей, один для заголовков; все иконки одного размера в своём ряду; строки одинаковой высоты; контраст текста ≥ 4.5:1.

### Светлая
canvas `#FAFAFA`, panel `#F4F4F5`, surface `#FFFFFF`, raised `#FFFFFF` (+ тень), fill-hover `rgb(0 0 0 / .04)`, fill-active `rgb(0 0 0 / .07)`,
border `rgb(0 0 0 / .08)`, border-strong `rgb(0 0 0 / .14)`, control-border `#8A8F98`, text `#111214`, text-secondary `#4A4E55`, muted `#6B6F76`,
accent `#4450D6` (белый 6.5:1), accent-text `#3B46C8`, success `#18794E`, warning `#9A6700`, danger `#C62F3C`.

### Главная кнопка — монохромная
Тёмная тема: фон `#ECEDEF`, текст `#0E0F11`. Светлая: фон `#111214`, текст `#FFFFFF`. Акцентный цвет — не для больших кнопок, а для: фокуса, выбранного, прогресса, линии «сейчас», ссылок, отмеченного чекбокса.

### Радиусы и тени
Карточка **12 px**, поле/кнопка/сегмент **8 px**, чип/бейдж **6 px**, диалог **14 px**; полностью круглое — только точки, аватары, кольца прогресса.
Тёмная: тени нет (линия 1 px + внутренний блик `inset 0 1px 0 rgb(255 255 255 / .04)`), всплывающие — `0 8px 24px rgb(0 0 0 / .5)`.
Светлая: карточки `0 1px 2px rgb(16 24 40 / .05)`, всплывающие `0 8px 24px rgb(16 24 40 / .12)`.

### Типографика
Шрифт текста — **Geist** (проверить покрытие кириллицы, включая «ё»; если неполное — **Inter Variable**); моноширинный для времени и таймеров — **Geist Mono** или JetBrains Mono (нужны только цифры и двоеточие). Самостоятельная загрузка (fontsource), `font-display: swap`, предзагрузка кириллицы.
Шкала: page title 24/30 · 600 · −0.02em; greeting (только «Сегодня») 28/34 · 600 · −0.025em; h2 16/22 · 600; body 14/20 · 400; small 13/18; caption 12/16; micro 11/14. Числа — `tabular-nums`.
Иконки — lucide, **16 px, stroke 1.5** в строках и меню; 14 px в плотных местах; 20 px в заголовках. Без цветных плиток под иконками.

### Движение
Длительности 100 / 150 / 220 мс, кривая `cubic-bezier(.2, 0, 0, 1)`. Появление — прозрачность + сдвиг 4 px за 150 мс. Без `linear()`-пружин, покачиваний, конфетти. Чекбокс — отрисовка галочки 120 мс. `prefers-reduced-motion` уважаем. «Праздничные эффекты» — настройка в «Настройках», **выключена** по умолчанию.

## 4. Компоненты
- **Button:** высоты 32 / 36; радиус 8; primary монохромная; secondary — поверхность + линия; ghost; danger — только для подтверждения необратимого.
- **Card:** поверхность, линия 1 px, радиус 12, отступ 16–20. Пропсы `tone`/`variant` остаются (совместимость), но **не красят фон**: тон — тонкая 2 px полоса или цвет иконки.
- **Tile/EmojiBadge:** без цветной подложки; эмодзи — просто символ 16 px в строке; «плитка» = иконка в нейтральном квадрате с линией, только где нужна опора.
- **Chip/Badge:** высота 20–22, радиус 6, нейтральный контур; заливка только у семантики и выбранного фильтра; прочие «тона» сводятся к нейтральному чипу с цветной точкой 6 px.
- **Segmented:** дорожка `fill-hover`, выбранный сегмент `raised` с линией; радиус 8.
- **Checkbox** 16 px, радиус 4; **Switch** 30×18; **Progress** 3–4 px акцентом на `fill-hover`; кольцо прогресса 2–3 px.
- **Sidebar:** плоская панель на всю высоту, линия справа, ширина 240 px; строки 32 px, радиус 6, выбранная — `fill-active` + иконка акцентом; подписи групп 12 px, muted, не заглавными; внизу статус, переключатель темы (иконка-кнопка), настройки.
- **Поля ввода:** высота 36, фон `surface`, линия `control-border`; фокус — кольцо 2 px акцента.
- **Toast:** `raised`, линия, радиус 10, 13 px, действие — текстовая ссылка «Отменить».
- **Логотип:** монохромный знак (четыре пересекающихся окружности 1.5 px, пересечение закрашено акцентом) + слово «Ikigai» Geist 600.
- **Фокус:** кольцо 2 px акцента со смещением 2 px везде.

## 5. Композиция «Сегодня» (образец для остальных страниц)
Заголовок: слева дата (13 px, muted) и приветствие (28 px, 600, с именем); справа компактная сводка в моноширинном шрифте: «план 3:00 · факт — · 0/3». Ниже одна строка-цепочка «мечта › цель › шаг» простым текстом с шевронами (без плиток). Основная колонка: «Сейчас/Дальше» → быстрая запись (поле с подсказкой `N`) → «Незавершённое» (сворачиваемый список) → расписание (блоки: фон `raised`, левая полоса 2 px по смыслу, время моноширинным, факт — тонкая акцентная дорожка; пропущенное — пунктир, без красного) → «Итог дня» вечером (простая строка цифр + оценка энергии 1–5 цифрами). Правая колонка: цель недели (полоса прогресса), задачи на день, напоминания, входящие — карточки или секции с линиями. Ни градиентов, ни неба, ни цветных плиток.
Тексты: «Незавершённое», «Пропущено», «Следующая задача», «На сегодня пока ничего»; без эмодзи-подписей и «милых» оборотов.

## 6. Что сохраняем из v2
Вся логика, данные, тесты, доступность (кольцо фокуса, ловушка фокуса, возврат фокуса, цели касания ≥ 44 px на сенсорных), PWA, командная палитра, «Входящие», разбор быстрой записи, отмена, журнал дня. Меняется оформление и композиция, не функции.
