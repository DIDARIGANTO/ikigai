# Ikigai — описание приложения (спецификация)

Дата: 13.09.2026 · Статус: утверждено пользователем

## 1. Что это

Личное веб-приложение для одного человека (владельца), которое связывает мечты и долгие цели с ежедневными делами
и замеряет эффективность через «план против факта». Работает в браузере (компьютер в приоритете, телефон — адаптивно).
Telegram-бот — второй вход: утренняя сводка, вечерний отчёт, запись задач сообщениями.

Главная цепочка: **Мечты → Цели (годы → год → месяц → неделя) → Задачи → День → Факт → Аналитика**.

Исследование рынка, на котором основаны решения: `docs/research/2026-09-13-market-research.md`.

## 2. Принципы

1. **Одно нажатие вместо заполнения.** Любой замер — максимум 1–2 действия (кнопки в Telegram, «Начать/Закончить»).
2. **Без наказания.** Серии не обнуляются; показывается процент за период. Несделанное переносится, а не «сгорает».
3. **ИИ предлагает — решаешь ты.** ИИ создаёт черновики (разбор сообщения, план недели), пользователь подтверждает.
4. **Бесплатно.** Все сервисы на бесплатных тарифах; платный только ИИ (оценка $1–5/мес).
5. **Каждая задача может вести к цели.** Связь с целью видна везде.

## 3. Стиль

«Горизонт» v2: тёплый, дерзкий, но дисциплинированный. Токены — в `@theme` (`src/styles/globals.css`), тёмная тема — отдельная палитра на `data-theme="dark"`
(выбор «Светлая / Системная / Тёмная» хранится в `ikigai.theme`, ставится до первой отрисовки). Холст `#F7F4EF` / `#12111A`, карточки `#FFFFFF` / `#1C1B27`,
текст `#1C1A26` / `#EEEDF5`, приглушённый ≥ 4.5:1; акцент — индиго `#5145CD` / `#9D95FF`. Палитра «дофамин» (индиго, мята, роза, янтарь, сирень, небо, лайм, коралл, солнце)
даёт тональные заливки `-soft` с текстом `-strong`; работа — индиго, личное — мята, важное — роза. Глубина — тон и мягкие тени (`shadow-raised/pop/overlay`), а не серые рамки;
границы полей ≥ 3:1, кольцо фокуса — сплошное 2 px акцентом. Радиусы: карточка 20, плитка 16, поле 12, кнопки и чипы — пилюли.
Шрифты свои: Onest — весь интерфейс, Unbounded — только приветствие, заголовки страниц, крупные числа и словесная марка; размеры — только токены (display 44, h1 30, h2 20, title 16, body 14, caption 12).
Знак — четыре круга света на тёмной плитке. Эмодзи — только на содержимом (задачи, цели, мечты, списки), хром — иконки Lucide 14/16/18/20 с толщиной 1.75.
Движение: 120/200/350 мс и пружина с перелётом ≈ 8 %, появление слоёв через `@starting-style`, «щелчок» чекбокса и конфетти по достижениям; при `prefers-reduced-motion` — без анимаций.
Все общие элементы — в `src/components/ui` (Segmented, Switch, Menu, Chip, Card, Tile, EmojiPicker, Toast с «Отменить», Modal/SidePanel), локальные копии не заводим.

## 4. Разделы (левое меню)

На компьютере — постоянная левая колонка; на телефоне — нижняя панель с 4 главными разделами + «Ещё».

| Раздел | Что внутри | Этап |
|---|---|---|
| **Сегодня** (первый экран) | Сводка дня: расписание по часам, задачи без времени, напоминания, цель недели, принцип дня. Кнопки «Начать/Закончить» у задач | 1 |
| **Календарь** | Вид месяц / неделя / день. Задачи и напоминания на датах; перетаскивание для переноса | 1 |
| **Доски** | Канбан: колонки «Надо → В работе → Готово» (можно добавлять свои). Доски «Работа» и «Личное» по умолчанию | 1 |
| **Цели** | Дерево по горизонтам: несколько лет → год → месяц → неделя. У цели — описание, срок, прогресс (% выполненных связанных задач), шаги-задачи | 1 |
| **Мечты** | Список «100 мечт»: картинка (по желанию), категория, галочка «исполнено» с датой. Кнопка «Сделать целью» | 1 |
| **Напоминания** | Всё, что запланировано на дату: разовые и повторяющиеся (ежедневно, еженедельно, ежемесячно, ежегодно — дни рождения) | 1 |
| **Списки** (свои блоки) | Пользователь сам создаёт любые списки с галочками и выбирает иконку: «Купить» (наушники, машина, квартира), «Прочитать», «Посмотреть» и т.д. У пункта — заметка, ссылка, цена (необязательно). Для списка с ценами — сумма «осталось купить». Каждый список можно закрепить в левом меню как отдельный блок | 1 |
| **Блокнот** | Место для всех мыслей: быстрые заметки, идеи, записи. Папки и поиск. Заметку можно превратить в задачу, цель или пункт списка | 1 |
| **Аналитика** | Метрики эффективности (раздел 7) | 2 |
| **Кодекс** | Личные правила и принципы; один приходит в утренней сводке | 2 |
| **Холст** | Бесконечная доска как Miro (Excalidraw). Карточки на холсте можно превратить в задачу/цель | 3 |
| **Тренировки** | Тренировка как тип задачи + журнал: упражнение, подходы, повторы, вес; прогресс по упражнению | 3 |

## 5. Сущности (данные)

- **Мечта**: название, описание, картинка, категория, исполнено (дата), связанная цель.
- **Цель**: название, описание, горизонт (`years` | `year` | `month` | `week`), родительская цель, мечта-источник,
  дата начала и окончания, статус (`active` | `done` | `dropped`). Прогресс вычисляется из связанных задач и подцелей.
- **Доска** и **колонка**: название, порядок; колонка имеет тип (`todo` | `doing` | `done`) для статистики.
- **Задача** (центральная сущность): название, заметка, сфера (`work` | `personal`), доска и колонка, цель (необязательно),
  дата, плановое начало (время, необязательно), плановая длительность (мин), фактическое начало и окончание,
  статус (`todo` | `doing` | `done` | `skipped`), счётчик переносов, источник (`web` | `telegram`), тип (`task` | `workout`).
- **Напоминание**: текст, дата, время (необязательно), повтор (`none` | `daily` | `weekly` | `monthly` | `yearly`).
- **Список**: название, иконка, порядок, закреплён в меню (да/нет). **Пункт списка**: текст, заметка, ссылка, цена, отмечен (дата), порядок.
- **Заметка** (Блокнот): заголовок, текст, папка, дата создания и изменения, источник (`web` | `telegram`).
- **Дневной журнал**: дата, энергия 1–5, качество сна 1–3, заметка.
- **Принцип** (Кодекс): текст, активен.
- **Недельный разбор**: неделя, цифры, текст ИИ, черновик плана.
- **Настройки**: часовой пояс (по умолчанию из браузера), время утренней (09:00) и вечерней (21:00) сводки,
  день недельного разбора (воскресенье 19:00), Telegram chat id.

## 6. Telegram-бот

- **Привязка**: на сайте в настройках кнопка «Подключить Telegram» → одноразовая ссылка `t.me/<бот>?start=<код>`.
  Бот отвечает только привязанному chat id, остальным — отказ.
- **Утренняя сводка (09:00)**: задачи на сегодня по времени, напоминания на сегодня (включая повторяющиеся),
  перенесённое со вчера, цель недели, принцип дня. Под задачами кнопки «▶ Начать».
  С этапа 2 — кнопки качества сна (плохо / норм / отлично).
- **Запись сообщением**: любой текст → ИИ разбирает на задачи, напоминания, пункты списков и заметки → бот показывает
  результат с кнопками «Сохранить / Изменить / Отмена». Сохраняется только после подтверждения.
  Примеры: «на следующей неделе в среду зал в 7, в пятницу позвонить маме» (задачи), «14 марта ДР Асель каждый год»
  (напоминание), «купить наушники» (пункт в список «Купить»), «мысль: сделать канал про дисциплину» (заметка в Блокнот).
  Если ИИ не уверен, куда отнести, — сохраняет в Блокнот.
- **Кнопки задачи**: «▶ Начать» / «■ Закончить» записывают фактическое время.
- **Вечерний отчёт (21:00, этап 2)**: список задач дня с кнопками «✓ Сделал / → Завтра / ✕ Отменить», оценка энергии 1–5.
- **Недельный разбор (вс 19:00, этап 2)**: итоги недели + черновик плана следующей недели от ИИ, кнопка «Открыть на сайте».
- **Голосовые (этап 2)**: голосовое → распознавание речи → тот же разбор, что и текст.

## 7. Метрики эффективности (Аналитика, этап 2)

| Метрика | Как считается |
|---|---|
| Выполнение | сделано / запланировано за день, неделю, месяц (%) |
| Точность планирования | медиана (фактическая длительность / плановая); «ты недооцениваешь задачи в 1,8 раза» |
| Пунктуальность | медиана (факт. начало − план. начало), мин |
| Время на цели | сумма факт. времени задач с целью / всё факт. время (%) |
| Хронические переносы | задачи с 3+ переносами |
| Энергия и результат | средний % выполнения в дни с энергией 4–5 против 1–2 (показывается после 14 дней данных) |
| Прогресс целей и мечт | % по каждой цели; исполнено мечт из 100 |

## 8. ИИ (этап 2; разбор сообщений бота — этап 1)

- **Разбор сообщений**: Claude Haiku 4.5, структурированный ответ (список задач/напоминаний: название, дата, время,
  длительность, повтор, сфера). В запросе — текущая дата, часовой пояс и список активных целей для привязки.
- **Недельный разбор и помощник**: Claude Sonnet 5 по сводным цифрам недели (не по сырым данным).
- **Распознавание голоса**: Groq Whisper (бесплатный тариф).
- Лимит расходов: не более 200 запросов ИИ в сутки; при превышении бот отвечает, что лимит исчерпан.
- Если ИИ недоступен — бот сообщает об ошибке и сохраняет текст как задачу «без даты» во входящих, ничего не теряется.

## 9. Технологии и инфраструктура (всё бесплатно)

| Часть | Решение |
|---|---|
| Сайт | Vite + React + TypeScript + Tailwind CSS, статический сайт, хостинг Vercel (Hobby). Локально-первый: данные хранятся в браузере (IndexedDB через Dexie) и работают без облака; облако подключается отдельным шагом через тот же интерфейс `Store` |
| База и вход | Supabase: Postgres (одна таблица `rows` с jsonb-данными по коллекциям) + Auth (вход по email-ссылке) + Row Level Security (доступ только владельцу) |
| Бот | Telegram Bot API, webhook на Supabase Edge Function `telegram-webhook` (не зависит от выбора фронтенда) |
| Расписание (09:00, 21:00, вс 19:00) | Supabase `pg_cron` + `pg_net` каждые 5 минут вызывают Edge Function `cron-tick` с секретом; функция сама решает, что пора отправлять с учётом часового пояса, и помечает отправку, чтобы не дублировать |
| ИИ | Anthropic API (ключ в переменных окружения) |
| Холст (этап 3) | Excalidraw (MIT) |

Секреты (ключи Supabase, токен бота, ключ Anthropic, секрет cron) — только в переменных окружения, не в коде.

## 10. Ошибки и надёжность

- Потеря связи на сайте: изменения ставятся в очередь и отправляются при восстановлении; индикатор «не сохранено».
- Сбой отправки сводки: повтор на следующем тике (до 3 раз), отметка «отправлено» только после успеха.
- Резервная копия: кнопка «Экспорт в JSON» в настройках (этап 1).
- Повторяющиеся напоминания вычисляются на лету из правила, а не хранятся копиями.

## 11. Проверка (тестирование)

- Модульные тесты (Vitest): расчёт повторов напоминаний, сборка утренней сводки, метрики, выбор «пора ли отправлять» по часовому поясу.
- Разбор ИИ: набор из ~20 примерных сообщений с ожидаемым результатом (проверяется вручную при изменениях промпта).
- Сквозные проверки (Playwright): вход, создание задачи, старт/стоп, перенос в календаре.

## 12. Этапы

- **Этап 1 — Ядро**: Сегодня, Календарь, Доски, Цели, Мечты, Напоминания, Списки, Блокнот, настройки + экспорт,
  бот: привязка, утренняя сводка, запись сообщением через ИИ, кнопки Начать/Закончить.
- **Этап 2 — Умный**: вечерний отчёт, дневной журнал (энергия, сон), Аналитика, недельный разбор, голосовые, Кодекс, ИИ-помощник.
- **Этап 3 — Расширение**: Холст, Тренировки, данные с часов (потребует нативной оболочки).

Каждый этап — отдельный план реализации. Первый план — этап 1.

## 13. Вне рамок

Несколько пользователей, команды, публикация в App Store / Google Play, платные подписки, полноценная работа без интернета (поддерживается только кратковременный обрыв связи, раздел 10).
