# Промт для создания сайта Ikigai

Как пользоваться: вставь **Промт 1** целиком в конструктор с ИИ (Lovable, Bolt, v0, Claude Code, Cursor).
Когда он готов и работает — вставь **Промт 2**, потом **Промт 3**. Не вставляй всё сразу: по этапам ИИ делает качественнее.

---

## ПРОМТ 1 — Ядро (этап 1)

```
Создай личное веб-приложение «Ikigai» — систему личной эффективности для одного пользователя (владельца).
Интерфейс полностью на русском языке. Компьютер в приоритете, но всё должно удобно работать в мобильном браузере.

## Идея
Приложение связывает мечты и долгие цели с ежедневными делами и замеряет эффективность через «план против факта».
Главная цепочка: Мечты → Цели (несколько лет → год → месяц → неделя) → Задачи → День → Факт → Аналитика.
Второй вход — Telegram-бот: утренняя сводка и запись задач/заметок сообщениями.

Принципы:
1. Любой замер — максимум 1–2 нажатия.
2. Без наказания: серии не обнуляются, показывается % за период; несделанное переносится, а не «сгорает».
3. ИИ только предлагает черновик — сохраняется после подтверждения пользователя.
4. Любая задача может быть привязана к цели, и эта связь видна везде.

## Технологии
- Фронтенд: React + TypeScript + Tailwind CSS (Next.js или Vite — как удобнее в этом инструменте).
- Бэкенд: Supabase — Postgres, Auth (вход по email magic link), Row Level Security (все таблицы доступны только владельцу, user_id = auth.uid()), Storage (картинки мечт).
- Серверная логика бота и расписания — Supabase Edge Functions.
- Расписание — Supabase pg_cron + pg_net: каждые 5 минут вызывать edge-функцию `cron-tick` с секретным заголовком.
- ИИ — Anthropic API, модель `claude-haiku-4-5` для разбора сообщений (структурированный JSON-ответ через tool use).
- Все секреты (TELEGRAM_BOT_TOKEN, ANTHROPIC_API_KEY, CRON_SECRET) — только в переменных окружения, никогда в коде.

## Стиль «Путь воина» (самураи, спартанцы, восточная культура)
Тёмная тема, строгий минимализм, без градиентов и лишних украшений.
- Фон: #0F0F10; поверхности/карточки: #19191B; границы: #2A2A2C
- Текст: #ECECEC; вторичный текст: #8A8A8E
- Золото #C9A227 — основной акцент, прогресс, активный пункт меню, главные кнопки
- Алый #C8102E — срочное, важное, просроченное, тренировки
- Шрифты (Google Fonts): заголовки — "Noto Serif JP"; логотип и латиница — "Cinzel" (разрядка букв); основной текст — "Inter"
- Иероглифы как знаки разделов рядом с названием: Сегодня 今, Календарь 暦, Доски 板, Цели 志, Мечты 夢, Напоминания 鐘, Списки 録, Блокнот 記, Аналитика 測, Кодекс 道
- Логотип вверху меню: «IKIGAI» шрифтом Cinzel, золотом, с иероглифом 生き甲斐 мелко под ним
- Карточки задач: тонкая цветная полоска слева (золото — обычная, алый — важная), скругление 8px
- Прогресс-бары тонкие (6px), золотые
- Плавные, короткие анимации (150–200 мс), никаких «прыгающих» эффектов

## Раскладка
- Компьютер: постоянное левое меню шириной ~240px (можно свернуть до иконок), справа — содержимое раздела.
- Телефон: нижняя панель с 4 кнопками (Сегодня, Календарь, Доски, Блокнот) + «Ещё» (открывает остальные разделы).
- Вверху содержимого: название раздела, быстрый поиск по всему (задачи, заметки, списки, цели), кнопка «+ Быстрая запись» (горячая клавиша N).
- Порядок меню: Сегодня, Календарь, Доски, Цели, Мечты, Напоминания, Списки (и под ними — закреплённые пользователем списки), Блокнот, Аналитика, Настройки.

## Разделы

### 1. Сегодня (первый экран после входа)
- Приветствие по времени суток и дата. Под ним — «Цель недели» (если задана) и строка прогресса дня: «Сделано 3 из 7».
- Расписание по часам (06:00–24:00): задачи с плановым временем в виде блоков по длительности. Линия «сейчас».
- Задачи без времени — отдельным списком «В течение дня».
- Напоминания на сегодня (включая повторяющиеся, например дни рождения).
- «Перенесено со вчера» — несделанные вчерашние задачи с кнопками «На сегодня / Выбрать дату / Отменить».
- У каждой задачи кнопки «▶ Начать» и «■ Закончить»: записывают фактическое время начала и окончания. Идущая задача подсвечена золотой рамкой, показывает таймер. Одновременно может идти только одна задача.
- После «Закончить» — задача отмечается сделанной, рядом мелко: «план 60 мин / факт 95 мин».

### 2. Календарь
- Виды: месяц / неделя / день. Задачи и напоминания на датах.
- Перетаскивание задачи на другую дату или время = перенос (увеличивать счётчик переносов).
- Клик по пустому месту — создать задачу на эту дату/время.

### 3. Доски (канбан как Trello)
- По умолчанию две доски: «Работа» и «Личное». Можно создавать свои.
- Колонки по умолчанию: «Надо» (тип todo), «В работе» (тип doing), «Готово» (тип done). Колонки можно добавлять, переименовывать, менять порядок; у каждой колонки есть тип для статистики.
- Карточки перетаскиваются между колонками и внутри колонки. Перенос в колонку типа done = задача сделана.
- Карточка открывается в боковой панели со всеми полями задачи.

### 4. Цели
- Дерево по горизонтам: «Несколько лет» → «Год» → «Месяц» → «Неделя». Вкладки по горизонтам + вид дерева.
- У цели: название, описание, горизонт, родительская цель, мечта-источник, даты начала и окончания, статус (активна / достигнута / отменена).
- Прогресс цели = % сделанных связанных задач и достигнутых подцелей. Показывать тонким золотым баром.
- Внутри цели: список её задач-шагов, кнопка «+ Шаг» (создаёт задачу, привязанную к цели, с выбором даты), подцели.
- Одну недельную цель можно отметить «Цель недели» — она показывается в «Сегодня» и в утренней сводке.

### 5. Мечты («100 мечт»)
- Сетка карточек с картинкой (загрузка в Supabase Storage, необязательно), названием, категорией.
- Счётчик вверху: «Исполнено 7 из 100».
- Галочка «Исполнено» (сохраняет дату) — карточка становится золотой с отметкой.
- Кнопка «Сделать целью» — создаёт цель, связанную с этой мечтой, и открывает её.

### 6. Напоминания
- Список всех напоминаний по датам: разовые и повторяющиеся (ежедневно / еженедельно / ежемесячно / ежегодно).
- Повторяющиеся вычисляются на лету из правила (не хранить копии). Для ежегодных показывать «через N дней».
- Поля: текст, дата, время (необязательно), повтор.

### 7. Списки (свои блоки)
- Пользователь создаёт любые списки: название + иконка (выбор из набора). Примеры по умолчанию: «Купить».
- Пункты с галочками. У пункта необязательно: заметка, ссылка, цена.
- Если в списке есть цены — вверху сумма «Осталось купить: X ₸» (валюта выбирается в настройках, по умолчанию ₸).
- Отмеченные пункты уходят вниз в свёрнутый блок «Готово».
- Переключатель «Закрепить в меню» — список появляется в левом меню как отдельный блок.

### 8. Блокнот
- Заметки для всех мыслей: заголовок + текст (простое форматирование: жирный, списки, чекбоксы, заголовки).
- Папки слева, поиск, сортировка по дате изменения. Автосохранение.
- Папка «Входящие» — сюда падают заметки из Telegram.
- У заметки кнопки: «→ Задача», «→ Цель», «→ В список» (создаёт соответствующий объект из текста заметки).

### 9. Быстрая запись (кнопка «+» и клавиша N)
- Одно поле ввода. Переключатель типа: Задача / Напоминание / Пункт списка / Заметка.
- Для задачи: дата, время, длительность, доска, цель, сфера (работа / личное).

### 10. Настройки
- Часовой пояс (по умолчанию из браузера), время утренней сводки (по умолчанию 09:00), валюта.
- Подключение Telegram: кнопка «Подключить Telegram» создаёт одноразовый код и показывает ссылку `https://t.me/<имя_бота>?start=<код>`. После привязки показывать «Подключено» и кнопку «Отключить».
- «Экспорт в JSON» — скачать все свои данные.

## Данные (таблицы Supabase, у всех: id uuid, user_id, created_at, updated_at; RLS: только владелец)
- profiles: timezone, morning_time (default '09:00'), currency (default 'KZT'), telegram_chat_id, telegram_link_code, telegram_link_expires_at, week_goal_id
- dreams: title, description, image_path, category, done_at, goal_id
- goals: title, description, horizon ('years'|'year'|'month'|'week'), parent_id, dream_id, start_date, end_date, status ('active'|'done'|'dropped')
- boards: title, position
- columns: board_id, title, kind ('todo'|'doing'|'done'), position
- tasks: title, notes, area ('work'|'personal'), board_id, column_id, goal_id, date, planned_start (time), planned_minutes, actual_start (timestamptz), actual_end (timestamptz), status ('todo'|'doing'|'done'|'skipped'), reschedule_count, source ('web'|'telegram'), kind ('task'|'workout'), position
- reminders: text, date, time, repeat ('none'|'daily'|'weekly'|'monthly'|'yearly')
- lists: title, icon, position, pinned
- list_items: list_id, text, note, url, price numeric, done_at, position
- note_folders: title, position
- notes: folder_id, title, body, source ('web'|'telegram')
- bot_drafts: payload jsonb, telegram_message_id, status ('pending'|'saved'|'cancelled') — черновики разбора сообщений до подтверждения
- sent_digests: kind ('morning'), date — отметка, что сводка за день отправлена (защита от дублей)

## Telegram-бот (edge-функция `telegram-webhook`)
- Бот отвечает ТОЛЬКО привязанному telegram_chat_id. Остальным: «Это личный бот».
- /start <код> — привязка чата к профилю (код одноразовый, живёт 15 минут).
- Любой текст → разбор через Claude (claude-haiku-4-5) в структуру:
  [{type: 'task'|'reminder'|'list_item'|'note', title, date, time, minutes, repeat, list_name, area, goal_id}]
  В запрос к ИИ передавать: текущую дату и время в часовом поясе пользователя, названия его списков, активные цели (id + название).
  Правила: «купить X» → list_item в список «Купить»; «мысль: …», «идея: …» и всё непонятное → note во «Входящие»; даты вроде «в пятницу», «через неделю», «14 марта» переводить в конкретные даты; «каждый год / ДР» → reminder с repeat yearly.
- Бот показывает результат списком («📌 Задача · пт 14:00 · Позвонить маме» и т.д.) с кнопками «✅ Сохранить», «✏️ Изменить», «✖️ Отмена». Сохраняет только после «Сохранить». «Изменить» — пользователь пишет исправление, разбор повторяется с учётом исправления.
- Если ИИ недоступен или ошибся — сохранить исходный текст заметкой во «Входящие» и сообщить об этом. Ничего не терять.
- Лимит: не более 200 запросов к ИИ в сутки.
- Кнопки «▶ Начать» / «■ Закончить» у задач в сообщениях бота записывают фактическое время, как на сайте.

## Утренняя сводка (edge-функция `cron-tick`, вызывается каждые 5 минут)
- Если в часовом поясе пользователя наступило morning_time и сводка за сегодня ещё не отправлена (sent_digests) — отправить в Telegram:
  «☀️ Доброе утро. Сегодня <день недели, дата>»
  • Цель недели и её прогресс
  • Задачи на сегодня по времени (с кнопкой ▶ Начать у каждой)
  • Задачи без времени
  • Напоминания на сегодня (включая ежегодные: «🎂 ДР Асель»)
  • Перенесено со вчера
  • Ссылка «Открыть Ikigai»
- Отметку «отправлено» ставить только после успешной отправки; при ошибке — повтор на следующем тике (до 3 попыток).

## Надёжность
- Оптимистичные обновления в интерфейсе; при потере связи — очередь изменений и индикатор «Не сохранено», отправка при восстановлении.
- Пустые состояния — приглашение к действию (например: «Запиши первую мечту»), а не «Здесь пусто».
- Подтверждение перед удалением.

## Проверка
- Модульные тесты (Vitest): вычисление повторяющихся напоминаний на дату, сборка текста утренней сводки, выбор «пора ли отправлять сводку» с учётом часового пояса, расчёт прогресса цели.
- Заполни базу демо-данными для владельца при первом входе (2 доски, 3 цели, 5 мечт, список «Купить», 1 заметка) с кнопкой «Удалить демо-данные» в настройках.

Сделай всё из этого промта. Разделы Аналитика и Кодекс в меню показать с пометкой «скоро».

## ПРОМТ 2 — Умный (этап 2). Вставлять после того, как Промт 1 работает

```
Продолжаем приложение Ikigai. Добавь этап 2, сохраняя стиль «Путь воина» и все принципы.

1. Дневной журнал: таблица daily_logs (date, energy 1–5, sleep 1–3, note).
2. Вечерний отчёт в Telegram (по умолчанию 21:00, время в настройках): список задач дня с кнопками
   «✓ Сделал / → Завтра / ✕ Отменить» у каждой и в конце оценка энергии кнопками 1–5. «→ Завтра» переносит задачу и увеличивает reschedule_count.
3. В утреннюю сводку добавь кнопки качества сна: «😴 Плохо / 🙂 Норм / 💪 Отлично» (пишется в daily_logs.sleep).

   - Выполнение: сделано / запланировано (%), график по дням

   - Пунктуальность: медиана (факт. начало − план. начало) в минутах

   - Хронические переносы: задачи с 3+ переносами
   - Энергия и результат: средний % выполнения в дни с энергией 4–5 против 1–2 (показывать после 14 дней данных, до этого — «Собираю данные: осталось N дней»)
   - Прогресс целей и мечт

5. Недельный разбор (воскресенье 19:00, настраивается): бот присылает итоги недели цифрами + текст от ИИ

   с кнопками «Сохранить план / Открыть на сайте». Таблица weekly_reviews (week_start, stats jsonb, ai_text, draft jsonb).

7. Раздел «Кодекс» (道): личные принципы (таблица principles: text, active). В утренней сводке — один случайный активный принцип.
8. ИИ-помощник: кнопка «Спросить» в Аналитике — чат с Claude, которому передаются сводные цифры за последние 4 недели и цели. Лимит 20 сообщений в день.
9. Серии без наказания: для повторяющихся задач показывать «% за 30 дней», не обнулять.

## ПРОМТ 3 — Расширение (этап 3)

```
Продолжаем Ikigai. Добавь этап 3 в том же стиле.

1. Раздел «Холст» (Miro-подобная бесконечная доска) на библиотеке Excalidraw (тёмная тема под наши цвета).
   Несколько холстов, сохранение в Supabase (таблица canvases: title, scene jsonb). Выделенный текстовый элемент можно превратить в задачу, цель или мечту кнопкой.
2. Раздел «Тренировки»: задача с kind='workout'. Журнал: таблица workout_sets (task_id, exercise, set_no, reps, weight_kg).
   Справочник упражнений пользователя, история по упражнению с графиком максимального веса, шаблоны тренировок.
   Кнопка «Повторить прошлую тренировку».
3. Подготовка к данным с часов: таблица health_daily (date, sleep_minutes, steps, resting_hr, hrv) и ручной ввод; в Аналитике — «сон и результат».
```
